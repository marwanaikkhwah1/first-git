Clinic Website

A simple and responsive clinic website created as a collaborative project.

About the Project

This project is a clinic website designed to provide a simple and user-friendly interface. The website includes two main pages:

• Sign In Page – Allows users to sign in to the website.
• Dashboard Page – Displays the main dashboard interface of the clinic website.
